# 反激开关电源 — 30-60V DC 输入 / 24V 3A，基于 UC3842

## 概述

- **拓扑**：单端反激 (Flyback)，原边峰值电流模式控制
- **控制器**：UC3842，峰值电流模式 PWM
- **输入**：30–60V DC 宽压**直接输入**（无前级 AC 整流 / 无 EMI 滤波级）
- **输出**：24V DC / 3A（额定 72W）
- **开关频率**：50kHz
- **反馈**：PC817 光耦隔离 + TLV431 基准（TL431/TLV431 混用教训见 §5.3 / §8.2），Type II 补偿
- **变压器**：PQ2620 (PC40)，三明治绕法，原副边 10:10、辅助绕组 10T，实测原边电感 27µH
- **副边整流**：基础版 MBR2060CT 肖特基（效率 75%–80%）；后升级**同步整流** UCC24612 + AGM18N20D，效率达 **85%**
- **输出性能**（实测）：纹波 30mVpp，启动无过冲，全负载区间稳压正常

> **设计说明**：输入为 30–60V DC 母线、输出 24V/3A。选反激而非 Buck 的出发点是**原副边电气隔离**（反馈经 PC817 跨隔离带采样）；若应用无隔离要求，该电压等级以同步 Buck 更高效。本机为去 AC 前级、聚焦 UC3842 峰值电流控制 + 同步整流的验证平台（由 AC 反激参考设计移植）。

> **参考说明**：本设计借鉴 `New Project_2026-07-11_22-49-55` 的整体思路（UC3842 + 光耦反馈 + 同步整流的架构），但**去掉了前级 220V AC 整流与 EMI 滤波，改为 30–60V DC 直接输入**，且变压器参数（PQ2620、匝比、电感量）为本项目重新设计，与参考工程不同。

## 2. 变压器设计

### 2.1 磁芯

PQ2620，PC40 / PC95 功率铁氧体，有效截面积 Ae=119mm²。采用**三明治绕法**降低漏感、提升耦合。

### 2.2 匝数与实测（以实际绕制版次为准）

| 绕组 | 匝数 | 线材 |
|---|---|---|
| 原边 Np | 10T | 多股漆包线 |
| 副边 Ns | 10T | 多股并绕 |
| 辅助 Naux | 10T（初始 7T，后加至 10T） | 解决 VCC 供电不足，见 §8.1 |

实测参数：**原边电感 27µH**（精准匹配设计目标）、**漏感 0.8µH**（占比 <3%，耦合优秀）、**100kHz 下 Q 值 80~110**（磁芯损耗小、绕制可靠）。

> **注**：定稿版参数规范（另文档）给出 12:12:8、Lp=42µH±5% 的目标值，计算书给出 12:12:8、Lp=30µH——与本次实测版不同，README 以实际绕制并电桥实测的版次为准。气隙打磨以 LCR 实测电感为验收标准，不按理论气隙直接加工。

### 2.3 反射电压、占空比与工作模式

VOR=25V。占空比 D = VOR/(Vin+VOR)：30V 输入 D≈0.455、60V 输入 D≈0.294，满载全程 D<0.5，UC3842 无需斜坡补偿。

**工作模式（满载，η=0.85，Pin≈85W）**：本设计原边电感较小，模式随输入电压跨越 CCM/DCM 边界——

- 导通期原边电流平均 I_on = Pin/(Vin·D)，纹波 ΔiL = Vin·D/(Lp·fs)，谷值 I_v = I_on − ΔiL/2。
- 30V 输入：I_on≈6.2A、ΔiL≈10.1A → I_v≈1.2A>0，为**浅 CCM**（纹波率 ~160%）。
- CCM/DCM 转换点由 I_v=0 反推约在 **Vin≈38V**；60V 输入 I_v<0，进入 **DCM**，Ipk=√(2·Pin/(Lp·fs))≈11.2A。

即"深度连续 CCM"并非本板实际工况；高纹波、大峰值是该电感量下的固有特征，其代价与选型影响见 §2.4、§3.2。若目标为全程 CCM（30% 纹波），Lp 需放大至 ~150µH 量级（改版方向，需加匝重绕）。

### 2.4 电流应力（计算）

满载 Pin = Po/η ≈ 85W（η=0.85），按 §2.3 两种工况分别核算：

| 输入工况 | 峰值 Ipk | 原边 Irms | 计算式 |
|---|---|---|---|
| 30V，浅 CCM | ≈11.3A | ≈4.6A | I_on(6.2A) + ΔiL/2(5.1A) |
| 60V，DCM | ≈11.2A | ≈3.5A | √(2·Pin/(Lp·fs)) |

选型按 **Ipk≈11.5A**（含裕量）计，MOS 与采样电阻均以此为准（§3.1、§3.2）。

## 3. 原边功率级

### 3.1 MOSFET

耐压 **150V 级**：漏极稳态应力 = Vbus + Vclamp = 60V + 40V = 100V（RCD 钳位核算见 §3.3），取 1.5 倍余量选 150V 级。

推荐 **IPP126N15N3G**（150V，Rds(on)≈12.6mΩ），或同级 150V OptiMOS（如 IPP083N15N3G，150V / 8.3mΩ）。

⚠️ **器件参数一律以原厂 datasheet 为准**：75V 级器件（STP75NF75、IRFB3607——后者实为 75V/80A/9mΩ，早期曾被渠道标为 150V 级，见 §8.7）在本输入范围下耐压不足，不可用。

### 3.2 原边电流采样

采样电阻 **0.05Ω**（2×1206 并联，按 ≥2W 额定选取）。满载原边峰值 Ipk≈11.5A（§2.4）→ 采样峰值电压 ≈0.58V，为 UC3842 CS 1V 阈值的 ~58%，留足裕量；原边 Irms≈4.6A → 电阻功耗 ≈1.1W，须按 ≥2W 选取（初版 0.075Ω 单颗即因裕量与功耗双不足故障，见 §8.4/§8.5）。

调试历史：初版 0.075Ω 偏大 → 满载触发 CS 限流、占空比锁 34%（§8.4）；采样电阻曾击穿失效（0.075Ω→20kΩ，§8.5）。两故障同源于初始峰值估算偏低，见 §8.7。

### 3.3 RCD 吸收（设计准则）

漏感储能经 RCD 钳位回馈母线。钳位电压设在 VOR（25V）之上加余量、约 35–40V；MOS 漏极应力 = Vbus + Vclamp = 最高 60+40 = 100V，远低于 150V 耐压裕量。具体阻容值以实际板设定为准。

## 4. UC3842 控制电路

### 4.1 芯片特性

UC3842 峰值电流模式 PWM 控制器：

- 启动阈值 16V（UVLO ON）/ 关断阈值 10V（UVLO OFF），6V 迟滞
- 5V 基准 VREF（±1%，50mA）
- 振荡器 `f ≈ 1.72/(RT×CT)`
- CS 脚 1V 阈值逐周期限流
- 图腾柱输出 ±1A 峰值驱动

### 4.2 频率设定

设计开关频率 **50kHz**，按 `f ≈ 1.72/(RT×CT)` 设定 RT/CT。

### 4.3 启动过程

```
输入直流 → 启动电阻向 VCC 电容充电 → VCC 升至 16V → UC3842 启动 PWM
         → 辅助绕组(10T)整流供电接管 VCC → 稳定工作
```

辅助绕组匝数不足会导致 VCC 在启动后掉电 → 芯片反复重启、电源打嗝（§8.1）。

### 4.4 限流保护

UC3842 CS 脚 1V 阈值。采样电阻 0.05Ω → 限流上限约 20A 原边峰值；满载峰值 Ipk≈11.5A（§2.4），裕量充足。CS 脚前 RC 滤波滤除前沿开通尖峰。

## 5. 反馈环路

### 5.1 PC817 + TLV431 隔离反馈

输出电压经分压网络（**R14=4.7kΩ / R27=3.9kΩ / R23=1kΩ**，复盘记录有效分压比约 1/19.2）取样到 TLV431 REF（**1.24V** 基准），TLV431 与内部基准比较后驱动 PC817 光耦 LED；二次侧反馈经光耦 → 一次侧 UC3842 COMP 脚，调节占空比。

```
Vout ≈ 1.24V × 19.2 ≈ 23.8V ≈ 24V
```

### 5.2 Type II 补偿

TLV431 阴极–REF 之间并联 RC 构成低频极点，滚降高频环路增益；光耦输出经 RC 滤波后馈入 UC3842 COMP 脚（Pin 1）。设计目标：穿越频率取开关频率的 1/10~1/5（约 5–10kHz）、相位裕量 ≥45°。补偿网络阻容值在实板调定（TLV431 阴极并联 R、C ［待补实值］），环路稳定性以 §7 全负载区间稳压正常、无振荡为验收。

### 5.3 设计要点

- **TL431（2.5V）与 TLV431（1.24V）极易混用**：引脚排布不同、基准电压相差约一倍，混用会使稳压目标偏移一半（24V→12V）。必须核对实物丝印、按实际芯片基准重配分压网络（§8.2）。
- **分压网络阻抗不宜过高**：否则 REF 引脚抽取电流在分压电阻上产生压降、抬高采样电压，导致轻载反馈误判"已达标"、占空比锁定、输出欠压（§8.3）。

## 6. 副边整流与同步整流升级

### 6.1 基础版：MBR2060CT 肖特基

60V/20A 肖特基整流。72W 输出时副边电流有效值约 4A，二极管导通损耗是主要损耗之一，实测效率 75%–80%。

### 6.2 升级：UCC24612 + AGM18N20D（效率 → 85%）

**思路借鉴参考工程 `New Project_2026-07-11_22-49-55`**。用同步整流 MOSFET 取代肖特基整流，降低副边导通损耗，效率由 75%–80% 提升至 **85%**。

UCC24612 高精度 SR 控制器，通过检测 SR MOSFET 漏极电压（Vds）判断开关时机：

1. **开通检测**：Vds < -300mV（体二极管导通）→ GATE 置高开通 MOSFET
2. **关断检测**：电流过零、Vds 趋向 0V（-50mV 阈值）→ 关断 GATE
3. **比例驱动**：轻载时减小驱动电压，降低待机损耗
4. **振铃抑制**：检测到 DCM 振铃时锁定输出，防止误开通

SR MOSFET 与肖特基并联，提供 SR 关断瞬间续流 + SR 失效时的冗余整流路径。AGM18N20D（200V/18A）耐压覆盖副边反向应力。

## 8. 调试记录（复盘）

### 8.1 辅助绕组匝数不足 → 打嗝

**现象**：上电后反复启动-关断，VCC 约 12V 跳变，空载/轻载输出仅 12V，光耦不导通、反馈失效。

**根因**：初始辅助绕组 7T 按低压工况设计，适配 24V 输出后感应电压不足，无法维持 UC3842 稳定 VCC → 芯片频繁重启。

**解决**：辅助绕组 7T → **10T**，全工况 VCC 供电稳定，打嗝消除。

### 8.2 TL431 / TLV431 混淆

**现象**：输出电压偏离设计值（12V），REF 脚钳位 0.75V。

**根因**：TL431（2.5V）与 TLV431（1.24V）引脚定义和基准电压都不同，且实物引脚焊接颠倒。初次修正焊接后 REF 可随输出变化，但输出仍 12V——核查丝印确认实物是 1.24V 的 TLV431，与原 2.5V 基准分压网络失配。

**解决**：核对实物基准，按实际芯片重配分压网络，REF 精准达到基准，24V 恢复。

### 8.3 分压网络阻抗偏高 → 轻载欠压

**现象**：轻载（18Ω/1.33A）输出 20V 偏低，占空比锁 31%，COMP 2.6V。

**根因**：分压电阻整体取值过大，分压回路静态电流过小，与 TLV431 REF 引脚固有抽取电流同量级 → 抽取电流在分压电阻上产生额外压降、抬高采样电压，反馈误判"已达标"并锁定占空比；负载越大偏移越明显。

**解决**：等比例降低分压电阻，提升分压回路静态电流，消除引脚电流引起的采样偏移。

### 8.4 满载限流锁占空比 → 输出受限

**现象**：满载（8Ω/3A）输出 13V，COMP 拉满 3V（环路全力调节），但 ISENSE>1V 触发 UC3842 逐周期硬件限流，占空比锁 34%。

**根因**：采样电阻 0.075Ω 偏大，满载原边峰值电流直接触发 CS 1V 阈值限流。

**解决**：采样电阻 **0.075Ω → 0.05Ω**，提升限流阈值裕量，满载 72W 正常输出。

### 8.5 采样电阻击穿

**现象**：开关管高频尖峰冲击原边采样回路，0.075Ω 采样电阻击穿至 20kΩ，CS 持续检测超高电压 → 芯片判定过流、永久封锁驱动，电源无输出。

**解决**：更换采样电阻，采样回路恢复。

### 8.6 测试点位错误（核心误区）

**现象**：负载端测量电压偏低，误判电源稳压失效。

**根因**：测试引线电阻 / 接触电阻产生压降。

**解决**：以**输出电容引脚根部**为核心测量基准（反馈采样点即输出基准），更换低阻测试线后电源端与负载端电压一致。

### 8.7 复盘：峰值电流估算偏低与选型链

将 §8.4、§8.5 与早期设计判断合并复盘：

- **采样故障同源**：设计初期按 Ipk≈10.46A 选型；复核（§2.4）满载实际峰值 ≈11.3A（30V 浅 CCM）/ ≈11.2A（60V DCM），初值低估约 8%。由此 0.075Ω 采样在满载下峰值压降 ≈0.85V，逼近 CS 1V 阈值（余量仅 15%），满载即触发逐周期限流、占空比锁 34%（§8.4）；同时 0.075Ω 在 Irms≈4.6A 下功耗 ≈1.6W，超出单片采样电阻能力，终致击穿（§8.5）。两故障是同一根因（峰值低估 → 采样裕量与功耗双缺）的两种表现，并非独立问题。
- **MOS 选型失误**：IRFB3607 曾以"150V/20A"入推荐表，核对原厂 datasheet 后确认实为 75V/80A/9mΩ，与所需耐压不符，已剔除（§3.1）。教训：分立器件额定一律以 datasheet 为准。
- **模式认知修正**：早期记作"CCM 深度连续"，实测复核为 30V 端浅 CCM、60V 端 DCM（边界 ≈38V，§2.3），峰值/有效值已按 §2.4 修正。
- **改版方向**：若需全程 CCM、压低峰值与 RCD 钳位损耗，可将 Lp 放大至 ~150µH（加匝重绕）；VCC 绕组可自 10T 回落至 ~8T（VCC≈18.5V），在 UC3842 16V UVLO 裕量与 30V 上限之间留足空间。
