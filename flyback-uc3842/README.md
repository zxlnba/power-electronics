# 反激开关电源 — 基于 UC3842

## 概述

- **拓扑**：单端反激 (Flyback)
- **控制器**：UC3842（8 脚 PWM 控制器）
- **额定输出**：24V / 3A (72W)
- **开关频率**：50kHz
- **反馈方式**：TL431 + PC817 隔离反馈 + Type II 补偿
- **变压器**：PQ2620 磁芯，三明治绕法，匝比 10:10

## 实测性能

| 指标 | 数值 |
|---|---|
| 效率 | 75% – 80% |
| 输出纹波 | 30mVpp |
| 启动特性 | 无电压过冲 |
| 负载调整率 | 全负载范围稳压正常 |
| 漏感 | 0.8µH (< 3% 初级电感量) |
| 原边电感量 | 27µH ± 5% |

## 变压器设计

- **磁芯**：PQ2620，PC40 材质
- **原边电感量**：27µH（研磨中柱气隙精确控制）
- **漏感**：0.8µH（< 3% 初级电感量）
- **绕制工艺**：三明治绕法（降低漏感，提升耦合效率）
- **辅助绕组**：初始 7 匝 → 优化为 10 匝（解决 VCC 供电打嗝）

## 关键故障排查

本项目经历多轮调试，系统解决以下问题：

1. **启动打嗝**：调整启动电阻 22k → 10k，增加 VCC 电容容量，辅助绕组 7 → 10 匝
2. **基准电压偏移**：定位 TLV431 (Vref=1.24V) 误用为 TL431 (Vref=2.5V)，更换后输出稳定
3. **逐周期限流误触发**：采样电阻 75mΩ → 50mΩ，恢复额定带载能力
4. **测试链路压降**：测试引线电阻导致远端测量电压偏低，更换低阻测试线后恢复正常

排查过程中先后排除的疑似问题：磁芯饱和、反馈环路故障、硬件钳位、ISENSE 噪声干扰——最终形成完整的电源调试方法论。
