# 1kW 原理样机开发

将 20kW 全桥 LLC 设计缩比至 1kW 进行原理验证，验证 LLC 谐振腔工作波形、ZVS 实现及闭环调压功能。

## 开发逻辑（4 章，按顺序读）

```
① 设计和样机 ──► ② PCB ──► ③ 调试代码 ──► ④ 缩尺 60V/300W
  01-设计样机/     02-PCB/      03-调试代码/       04-60V缩尺300W/
```

| 章 | 目录 | 内容 |
|---|---|---|
| **① 设计和样机** | [`01-设计样机/`](./01-设计样机/) | 三块板（驱动板/采样板/主功率板）原理图设计、工程开发文档、数字电压环设计 |
| **② PCB** | [`02-PCB/`](./02-PCB/) | 三块板 PCB 文件（Gerber + 嘉立创 EDA 工程） |
| **③ 调试代码** | [`03-调试代码/`](./03-调试代码/) | 采样固件（STM32G474）+ ADC 调试日志 |

| 项 | 状态 |
|---|---|
| 电压采样板 | ✅ 读数准确稳定 ±0.1V（VREFINT 归一化 + 0V 慢速校零，见 `03-调试代码/调试日志/`） |

| 60V 缩尺腔 | ✅ 已落地：Lr=8.2µH / Cr=470nF / Lm=26µH（新变压器 1:1、6T，实测 fr≈75kHz 增益=1，副边增益健康） |

## 缩比参数

| 参数 | 20kW 设计 | 1kW 样机 |
|---|---|---|
| 输入电压 | 800V DC | 360–440V DC |
| 输出架构 | ±400V / 800V 可切换 | ±200V 双输出 / 400V 单输出 可切换 |
| 额定功率 | 20kW | 1kW |
| 谐振频率 | 107kHz | 107kHz（保持一致） |
| 变压器磁芯 | PC95 | PQ35/35 PC95 |
