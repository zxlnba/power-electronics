# 60V/300W 缩尺 LLC 样机

**1kW 全桥 LLC 数字控制方案的低压缩尺验证 · 全桥拓扑 · STM32G474 控制 · 以实际到手器件参数为准**

---

## 1. 样机概述

将 1kW 全桥 LLC 数字控制方案缩尺到 **60V/300W**，在 300W/60V 直流电源上完成功率级与控制环路的低压验证。

| 项 | 说明 |
|---|---|
| 拓扑 | 全桥 LLC（原边 ±Vin 方波，4 MOSFET） |
| 增益关系 | Vout = M × Vin（变压器 1:1） |
| 控制 | STM32G474 · HRTIM TimerD REP 中断 · 闭环（Kp/Ki + 撞钳位冻结抗饱和，见 §6.4）+ 软启动 + 过流保护 |
| 测试电源 | 300W / 60V DC（输入电流以电源屏显为准） |

## 2. 实际器件参数

以到手器件为准。原设计参数（Lr≈7µH、Lm≈24µH、fr≈87.7kHz）与实际到手器件存在偏差，下表及配套脚本均已按实测修正。

| 参数 | 数值 |
|---|---|
| 谐振电感 Lr | **8.2µH** |
| 谐振电容 Cr | **470nF**（CBB） |
| 励磁电感 Lm | **26µH**（励磁比 k = Lm/Lr ≈ 3.2） |
| 谐振频率 fr | **≈75kHz**（实测增益=1；理论计算 ≈81kHz，差 6-8% 属寄生/容差） |
| 特性阻抗 Z0 | ≈ 4.18Ω（√(Lr/Cr)） |
| 变压器 | PQ35 · 1:1 · 6T（原边 6T，副边全绕组 6T = 3T+3T 中心抽头）· 气隙 0.32mm |
| 副边整流 | RHRP860（600V/8A 快恢复）→ 更换为 **MBR10100**（10A/100V 肖特基） |

满载工作点（M=1，fs=fr）：

| 负载 | 功率 |
|---|---|
| 40Ω（两路 20Ω） | ~80W |
| 12Ω（4× 3Ω/100W 串联） | 300W |

变压器绕制规格见 [`PQ3535变压器绕制设计.md`](./PQ3535变压器绕制设计.md)。

## 3. 为什么需要 60V 专用腔（设计基础）

现 1kW 谐振腔按额定 **400V/1kW** 设计（Z0=181.5Ω）。接到 60V 电源上，负载等效阻抗过低、增益封顶 M≈1.0 且无升压区，60V 下跑不出瓦级功率。因此单独设计 60V/300W 专用腔。

设计目标：输入 60V、输出 60V（M=1）、满载 300W、增益曲线平坦有升压裕量、扫频不塌。

FHA 设计要点（`llc_rescale.m` 计算）：

| 参数 | 设计值 | 实际到手 |
|---|---|---|
| Lr | 7µH | **8.2µH** |
| Cr | 470nF | **470nF** |
| Lm | 24µH | **26µH** |
| fr | 87.7kHz（计算） | **≈75kHz（实测增益=1）** |
| Z0 | 3.86Ω | **4.18Ω** |

功率阶梯（M=1，Vout=60V）：**12Ω/300W 满载** · 15Ω/240W · 20Ω/180W · 30Ω/120W · 46Ω/78W。

## 4. 增益曲线

一张图两面板（`llc_rescale.m` 生成）：**左** = 满载 12Ω 下不同励磁比 k=Lm/Lr 增益比对 → 选取 Lm；**右** = 选定 k=3.2（Lm=26µH）后各带载增益曲线（含实测工作点）。

![增益曲线：左 = k 比对选取 Lm，右 = 各带载曲线](LLC_gain_curves_Lm26uH.png)

**左面板（选取 Lm）**：满载 12Ω（Q≈0.43）下比较 k=2.5~5.0（Lm≈20~41µH）。增益差异集中在低频升压区，**k=3.2（Lm=26µH，PQ35 气隙 0.32mm）** 在 60~80kHz 区段平坦、有升压裕量（M 略高于 1），且 0.32mm 气隙装配一致性好。k 在 1:1 定增益（调节用）下不是敏感参数，选取装配性最好的 k=3.2。

**右面板（各带载）**：实线为满载 12Ω（Q≈0.43）与验证负载 40Ω（Q≈0.13），虚线为 15/20/30/46Ω。**黑色圆点为实测工作点**（副边整流前方波，40Ω 验证负载）：fr≈75kHz 增益=1、80kHz 满摆 60V、100kHz ≈50V（M≈0.85），落在 40Ω FHA 曲线附近，与实测 fr 低于理论 81kHz 约 6-8%（寄生/容差）一致。

> 注：副边整流前方波增益健康——压降不出在这里，输出压降根因 = 整流管 RHRP860 VF（见 §5）。

## 5. 工程日志

### 5.1 现象

60V 输入下按输出电压计算，增益/效率低于预期。

### 5.2 排查与排除的假说

对副边整流前（变压器副边）方波增益逐项检查：

| 检查项 | 结论 |
|---|---|
| 谐振腔（Lr/Cr/Lm） | 无异常 |
| 副边方波增益 | **健康**：fr≈75kHz 增益=1；60V 输入 80kHz 满摆 60V（M≈1）、100kHz ≈50V（M≈0.85） |
| 设计 / 器件 | 无异常 |

排查过程中曾怀疑并被实测排除的假说：谐振腔增益曲线封顶（高频/低频掉压）、设计点不匹配、容性硬开关区、死区占空丢失、固定损耗未计入预算——副边增益实测健康，均非压降来源。

### 5.3 结论

副边整流前方波增益健康——不是谐振腔的问题、不是设计的问题、不是器件异常的问题。输出压降全部来自**整流管**。

- 整流管 **RHRP860**（600V/8A 快恢复）正向导通压降 VF 随电流 ~1.0–2.1V/只，全桥整流每半周两只串联，共 **~2–3V**。VF 是随电流变化的曲线，2.1V 为 8A 额定上限，不是固定值。
- 该管按 1kW 高压（400V）系统选取，不能直接用于 60V 缩尺样机。

### 5.4 修复与验证

- 整流管更换为 **MBR10100**（10A/100V TO-220AC 肖特基，单管；非 CT 双管、非 60V 档）：
  - VF ~0.5–0.6V/只，两只串联 ~1.2V，输出恢复 **+2–3V**；
  - 无反向恢复，去除高频开关损耗。
- **验证点：60V / 80kHz / 40Ω → 输出预期 ≈57–58V**（RHRP860 时实测 ≈55–56V）。

### 5.5 关键调试教训

- **输入电流一律以电源屏显为准**，不用万用表 DC 档。
- **低频 95kHz + 轻载曾出现 MOS 发烫 + 40W 输入**（2026-08-10），改在谐振点（fr）验证；后续判定属大循环电流等其他原因，非容性区硬短路。
- **采样时序修复**：ADC 640 周期 → 12.5 周期（~2.4µs），HRTIM 开关周期边界软件触发、相位锁定无拍频；固件三处 bug（TIMERINDEX 下标、`HRTIM_CR2_SWU` 宏不存在、只写 PER 不写 CMP1 丢 50% 占空比）。
- **采样读数演进与校零方案**（VREFINT 归一化、0V 慢速校零→定死基线、VDDA 漂移、显示侧慢低通抑制 >10Hz 噪声）见 [`01-设计样机/环路设计/README.md`](../01-设计样机/环路设计/README.md) 与 [`03-调试代码/调试日志/`](../03-调试代码/调试日志/)。
- **完整测试方案与早期逐项分析**（含早期已被实测修正的结论）：[`scaled-low-voltage-test-plan.md`](./scaled-low-voltage-test-plan.md)、[`缩尺方案与闭环固件测试报告.docx`](./缩尺方案与闭环固件测试报告.docx)、[`llc_theory.m`](./llc_theory.m)、[`llc_sim.m`](./llc_sim.m)。

### 5.6 损耗核算（2026-08-21）

三个负载工况（40Ω 轻载 / 20Ω 半载 / 12Ω 满载）效率之谜均已破解：**不是未知损耗，是循环电流（4.2A 励磁恒流 + 负载基波）过真实电阻的 I²R。**

**统一工作点**：全桥 LLC、n=1:1、M=1、fs=fr≈75kHz、V_bus=56.5V、V_out=56V（整流后）。V_fund_rms=(4/π)·56.5/√2=50.9V；I_mag_peak=56.5/(4×75k×26µ)=7.24A 峰 → I_mag_rms=7.24/√3=**4.18A RMS（与负载无关，恒流）**。

**谐振电流分解**：

| 分量 | 数值 | 说明 |
|---|---|---|
| 负载基波 I_load | P_out/50.9 | 传递功率的部分（20Ω 半载 ≈3.2A） |
| 励磁循环 I_mag | ≈4.2A RMS | I_mag_peak = Vin/(4·fs·Lm) ≈ 57/(4×75k×26µ) ≈ 7.3A 峰值，三角波 → 4.2A RMS，**与负载无关** |
| 腔体电流 I_tank | √(I_load²+4.18²) | 20Ω 半载 **≈5.3A RMS**，恒流分量占大头 |

**四负载核算（V_out=56V）**：

| 负载 | P_out | I_load 基波 | I_tank | 总损耗（冷→热） | P_in | 效率 |
|---|---|---|---|---|---|---|
| 40Ω 轻载 | 78W | 1.54A | 4.45A | 18→24W | 96-102W | 77-81% |
| 20Ω 半载 | 157W | 3.08A | 5.20A | 29→36W | 186-193W | 81-85%（**实测 83.6%**） |
| 12Ω 满载 | 261W | 5.13A | 6.62A | 49→60W | 310-321W | 81-84% |
| 15Ω 验证 | 209W | 4.11A | 5.86A | 38→47W | 247-256W | 81-85%（**实测 84%**） |

> 输入 DC 电流 ≠ 谐振 AC 电流：40Ω 轻载输入仅 1.7A，腔体却流 4.45A——循环分量在电源屏显上看不见，但恒烧 I²R 并驱动 75kHz 啸叫（磁致伸缩），轻载同样叫。

**损耗明细（逐项计算，W，冷 → 热）**：

| 损耗项 | 计算式 | 40Ω | 20Ω | 12Ω |
|---|---|---|---|---|
| MOS 导通 | 2×I_tank²×0.19（热 ×1.7） | 7.5 → 12.8 | 10.3 → 17.5 | 16.6 → 28.3 |
| MOS 开关（ZVS 关断） | 4×½×56.5×I_off×25ns×75k | 1.3 | 1.6 | 2.0 |
| 输入链 NTC 5D20 | I_in²×0.45（热态） | 1.3 | 4.9 | 12.6 |
| 输入链防反 RHRP30120 | I_in×1.15（1200V 管 VF 高，**过选**） | 2.0 | 3.8 | 6.1 |
| 副边整流 MBR10100 | 0.5×I_out | 0.7 | 1.4 | 2.3 |
| 磁件交流铜损 | I_tank²×0.15（区间 0.08-0.25；75kHz 趋肤深度 0.24mm，AC R = 2-5× DC R） | 3.0 | 4.1 | 6.6 |
| 磁芯 PQ35+Lr | Steinmetz，B=0.16T@75kHz（**恒**，~9.3cm³） | 2.5 | 2.5 | 2.5 |
| **合计** | | **18 → 24** | **29 → 36** | **49 → 60** |

**规律**：轻载损耗以恒流项为主（励磁驱动 MOS 导通 + 磁损 + 输入链），重载损耗随 I² 猛涨（MOS + NTC + 防反）。20Ω 点估 29-36W 覆盖实测 31W。

> ⚠️ 本表开关项仅计 **ZVS 关断损耗**（开通近似零）；2026-08-23 实测发现开通叠区（开通电阻 20Ω 过慢）损耗远大于此，主体即开通叠区，见 §5.11。

**效率现状**：

| 负载 | P_in | 效率 | 状态 |
|---|---|---|---|
| 40Ω 轻载 | 96-102W | 77-81% | 计算值（待实测确认） |
| 20Ω 半载 | 186-193W（**实测 189W**） | 81-85%（**83.6%**） | 实测锚点 |
| 12Ω 满载 | 310-321W | 81-84% | 计算值（**已超 300W 电源限流**） |
| 15Ω 验证 | 247-256W（**实测 ~249W**） | 81-85%（**实测 84%**） | **实测确认**（模型 38-47W 覆盖实测 40W） |

> ✅ **模型双点验证（2026-08-21）**：20Ω（31W 实测 vs 模型 29-36W）与 15Ω（40W 实测 vs 模型 38-47W）两个独立负载的损耗均落进模型区间 → 损耗账成立。**12Ω 减损前 P_in 已超 300W 电源限流**——这正是 12Ω 满载跑不满的原因之一，减损后能压回限内。

**"MOS 不烫"疑点的两种合理解释**：①有散热片（损耗真实、壳温正常）；②I²R 大部分落在磁件交流铜损（Lr/变压器比 MOS 烫）。
**判别法**：满载跑 1 分钟后按 Lr → 变压器 → MOS → NTC 顺序摸温；用示波器测母线电容两端 V_bus 与整流前 V_sec，把输入链损耗和整流损耗精确拆分。

**三处"1kW 高压器件搬 60V 台架"（同一病根，系统性教训）**：
1. 整流 RHRP860（600V/8A 快恢复）→ VF 2-3V ✅ 已换 MBR10100；
2. MOSFET MMF65R190（650V/190mΩ）→ 导通 10.5-19W ⏳ 待换（§5.7）；
3. 防反 RHRP30120（1200V/30A 超快）→ VF 损耗 2-6W ⏳ 待换（输入链修复，见下）。

**输入链修复（另省，随负载缩放）**：

| 项 | 现状 | 改法 | 40Ω/20Ω/12Ω 省 |
|---|---|---|---|
| NTC 5D20 | 热态 0.45Ω | 继电器延时旁路 | 1.3 / 4.9 / 12.6W |
| 防反 RHRP30120 | 1200V 超快，VF~1.15V | 换 100V 肖特基（MBR2045 类，VF~0.45V） | 1.2 / 2.3 / 3.7W |

**天花板与前提**：剩余不可削减 = 磁件交流铜损 + 整流 + 开关 + 铁损 ≈ 7-18W，随负载缩放——这是本腔（Lm=26µH 循环电流 4.2A 恒流）的天花板。**若此板以后上 400V 额定，MOS 耐压不可降级**，上述选型仅适用于 60V 台架。12Ω 满 300W 需 Vout=60V（M=1.06），电流 ×1.07，损耗再 +~6W——该档在 300W 电源上必须先减损。

### 5.7 MOSFET 选型（2026-08-21）

**根因**：MMF65R190（650V/190mΩ）按 400V 额定选取，用在 56.5V 母线上耐压严重过剩，Rdson 190mΩ 成为损耗大头（10.7-19W）。降耐压到 150-200V 档，Rdson 降一个量级。

**三负载导通损耗（冷态，W；约束：目标每负载 MOS 导通 ≤ ~2W，P_cond=2×I_tank²×Rds）**：

| 型号 | Rds@10V | 40Ω | 20Ω | 12Ω | 判定 |
|---|---|---|---|---|---|
| MMF65R190（现状） | 190mΩ | 7.5 | 10.3 | 16.6 | 过选，损耗大头 |
| **IRFB4227** | 26mΩ | 1.03 | 1.40 | 2.28 | **推荐**（货源充足/价格低/余量 3.5×） |
| FDPF047N15 | 4.7mΩ | 0.19 | 0.25 | 0.41 | 损耗最优 + TO-220F 全塑封（免绝缘处理） |
| IRFB4110 | 4.5mΩ | 0.18 | 0.24 | 0.39 | 余量仅 1.77×，贴边不推荐 |
| IRF640N | 180mΩ | 7.1 | 9.7 | 15.8 | 与现管同级，替换无收益 |

**注意（TO-220 与 TO-220F）**：现板 4 管为 **TO-220F 全塑封**（背板塑料绝缘），可共用金属散热片直接拧。**TO-220 金属背板 = 漏极带电**：全桥 4 漏极电位各不相同（高压侧 = 母线 56.5V，低压侧 = 摆动中点），共用一块散热片 = 4 漏极短路 → 一上电即炸。换金属背板管必须每管独立散热片互不接触，或垫硅胶/云母绝缘垫 + 螺丝绝缘垫圈；省心做法 = 买 TO-220F 全塑封版。IRFB4227 与 FDPF047N15 导通只差 ~1.2W（≈0.6 个效率点），按货源 + 安装安全定：IRFB4227 货源充足、价格低；FDPF047N15 全塑封免绝缘处理。

**预计收益（热态点估）**：

| 负载 | 现状 | 换管（IRFB4227） | +输入链修复 |
|---|---|---|---|
| 40Ω | ~79% | ~86% | ~89% |
| 20Ω | 83.6%（实测） | ~88% | ~92% |
| 12Ω | ~83%（且超限流） | ~88%（~297W） | ~93%（281W，**回限内**） |

> MOS 导通 10-19W → 冷态 1.0-2.3W（12Ω 满载最高，热 ×1.7），效率 82-84% → **88-90%**（配合 NTC 继电器旁路再 +2-3 点）。剩余 ~10-13W 为磁件交流铜损 + 铁损 + 整流 + 输入链，是本腔（Lm=26µH 循环电流）的天花板。

### 5.8 驱动板上拉电阻异常（2026-08-21）

"昨天工作异常"排查最终定位：**驱动板上二管的上拉电阻阻值劣化 3.3Ω → kΩ 级**，高压侧栅极充电慢、半导通 → 异常功耗与工作异常。换新电阻后恢复调试。**建议检查其余 3 路栅极电阻**（同一批插件电阻）。

### 5.9 变压器啸叫定性 = 磁致伸缩（良性，2026-08-21）

啸叫由**腔体谐振电流 + 磁通**（B∝Vin/fs）驱动，是磁芯机械振动（磁致伸缩），**不是打火/放电**。证据：旧变压器叫得更离谱且长时间运行幸存；新变压器绕制更好仍会叫。输入电流小 ≠ 腔体电流小（§5.6），故 40Ω 轻载在 ~70kHz 同样开始叫。**判定标准：叫声随负载/频率变化而器件温升正常 → 无需处理。**

**实测修正（2026-08-21）**：初测判断为"固定 I_in≈2.5A 开始叫"（数据有误，已更正），复测实为 **fs≈85kHz 开始叫**（当时输入仅 ~1.5A），叫声随 fs 降低/电流增大而变响。**onset 由频率定、与负载无关** → 变压器磁芯磁通 **B∝Vin/fs 在 85kHz 达 ~0.14T** 的可闻阈值（B₈₅ₖ=0.141T、B₇₅ₖ=0.16T、B₇₀ₖ=0.172T，离饱和 0.4T 很远，纯声学门槛非磁饱和）。因正常工作点 fr≈75kHz 低于 85kHz，**整个正常工况都在阈值之上**，故 40Ω/70kHz 亦叫、且越近 fr 越响；Lr 磁通（∝I_tank）只叠加响度、不决定 onset（onset 声源 = 变压器磁芯）。想安静：提高 fr（改 Lr/Cr）让工作点跑进安静区，或给磁芯加机械阻尼（灌胶/夹紧）——台架用途良性无需处理。

**模型确认（2026-08-21）**：20Ω 与 15Ω 带载 onset 均在 ~85kHz、与负载无关 → **频率/磁通（B∝Vin/fs）驱动模型成立**，电流驱动说法排除。

### 5.10 增益区边界澄清（2026-08-21）

**低于 fr 不是容性区，是升压区（M>1）**。容性/硬开关边界在**增益峰值频率**——本腔 20Ω 下 ≈40kHz（fn≈0.5-0.52），远低于 fr≈75kHz。60V 母线靠升压区补偿整流管压降，是必须的工作区间。MOS 全程保持感性区 ZVS（无过热损坏）。2026-08-10 的"95kHz 轻载 MOS 发烫 + 40W 输入"属大循环电流等其他原因（见 §5.5）。

### 5.11 剩余 30W 损耗根因 = 开通叠区（2026-08-23）

换 IRFB4227（26mΩ）后导通只剩 ~1.5W，但 15Ω 满载仍 ~30W 损耗、MOS 发烫。逐项排除后定位：**根因 = 开通叠区损耗**——开通电阻 20Ω 太慢，每周期 MOS 在放大区（Vds×Id 重叠）停留过长，损耗随负载电流 I² 放大（满载 15Ω 烫、空载不烫）。

**修复与验证**：开通电阻 **20Ω → 10Ω**（关断路径不变：20Ω∥(10Ω+反接二极管)≈6.7Ω）→ **MOS 发热大幅下降、效率算到 90%+**。慢开通无 ZVS 代价、快关断保死区余量，对称性安全。开通电阻下限 ~3Ω：再小会抬升 dI/dt、中点过冲，并耦合至对管开通（EMI）。

**已排除的假设**：
- **死区调整对损耗无影响**：HRTIM 软件死区 0→200ns（DTI、DIV1@170MHz、DTR=DTF=34）+ 驱动板硬件 250ns = 总 ~450ns，效率不变；
- **栅极负压摇铃非损耗来源**：对管关断死区内 Cgd 注入 Miller 电流，两管栅极均出现摇铃、负向峰值 -10V；但 ZVS 干净（无开通尖峰/米勒平台）、470pF Cgs 无改善，排除为损耗来源；
- §5.6 损耗明细中"MOS 开关（ZVS 关断）1.3-2.0W"为低估——20Ω 开通时实际远大于此，主体即开通叠区。

**HRTIM DTxR 位段要点**：TimerD 的 DTxR 中 **bit9=SDTR（符号位），SDTR=1 = 负死区 = 上升沿提前 = 两管交叠**（直写 0x2222 即置位该位，产生交叠）。须使用 `HAL_HRTIM_DeadTimeConfig`，RisingSign/FallingSign 取 POSITIVE（=0，延迟=空隙）。60V 测试工程 `LLC_60V300W\开环扫频\Core\Src\hrtim.c` 采用该写法。

**效率测量（温漂）**：负载电阻热态阻值向下漂（负 TCR）→ 效率须用**实测 V×I**（万用表测输出电压 × 输出电流）计算；用 V²/R_nominal 只能得到保守下限。

## 6. 测试方案与闭环固件

### 6.1 测试准备

- 电源：300W/60V DC，输入电流以电源屏显为准
- 负载：40Ω（两路 20Ω）；满载 12Ω（4× 3Ω/100W 串联）
- 测量：示波器测桥臂中点 Vds、副边方波、输出

### 6.2 上电时序

1. 控制板上电，HRTIM 以最低增益频率（fr 以上）起步，无母线无功率；
2. 合 60V 母线（低压预充，抑制启动浪涌）；
3. 软启动到谐振点，闭合环路。

### 6.3 测试步骤

1. 开环极性验证：固定频率扫频（fr 上下），确认 Vout 随 fs 变化方向正确（fs 越高 Vout 越低）；
2. 谐振点验证：fs = fr ≈75kHz，副边满摆 60V 方波（M=1）；
3. 整流后验证：输出 ≈57–58V（更换 MBR10100 后）；
4. 负载阶跃：切换负载，观察输出回落与恢复；
5. 过流保护：短接输出，确认触发保护并停功率级。

### 6.4 采样与控制（固件）

- 采样：ADC 12.5 周期（~2.4µs），HRTIM 开关周期边界软件触发，相位锁定，无拍频；
- 控制：HRTIM TimerD REP 中断内完成采样 → 状态机（开环/软启动/闭环/故障）→ 频率环输出频率；60V 缩尺闭环固件为显式 **Kp/Ki + 撞钳位冻结积分抗饱和 + 缓动限幅**——初版 2p2z 于 2026-08-14 实测腔增益极平（≈0.33V/kHz）后替代；
- 软启动：fr 以上起步，斜坡逼近谐振点，抑制启动浪涌与闭环切入过冲；
- 固件参数切换：60V 低压段 `LC_K_GAIN_SCALE=6.667`、额定 400V 段 `=1.0`；vref、过流阈值按测试目标设定。
