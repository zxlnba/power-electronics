# PQ35/35 变压器绕制设计（60V/300W 缩尺腔 · 实际器件版）

> **本文档给出 60V/300W 缩尺腔新变压器的完整绕制规格。**
> 样机概述与实际器件参数见 [`README.md`](./README.md)。
> 原方案按 **Lr=7µH / fr≈87.7kHz** 设计；**实际到手的器件是
> Lr=8.2µH、Cr=470nF**（实测 fr≈75kHz，2026-08-18），本文档按实际器件重算，
> 是本变压器的**权威绕制依据**。
> 2026-08-13：励磁比经"1:1 稳压 + 时域仿真"核对后定 **k=3.2（Lm=26µH）**，
> 与 README 原方案 k≈3.43 同量级。气隙 0.32mm 比大 k 方案（0.20mm）好垫好磨，
> 满载升压裕度反而更大（仿真：最低可稳压输入 k=3.2→39V，k=5→48V）。

---

## 1. 实际器件与工作点

| 项 | 值 | 说明 |
|---|---|---|
| **Lr** | **8µH** | 已到手（谐振电感） |
| **Cr** | **470nF** | 已到手（CBB 谐振电容） |
| **fr** | **≈ 82.1kHz** | 1/(2π√(8µ·470n)) |
| Z0 | 4.13Ω | √(Lr/Cr) |
| 输入/输出 | 60V → 60V | 1:1 稳压，M=1 @ fr |
| 满载 | 300W（12Ω） | Q = 4.13/0.8106·12 ≈ 0.42 |
| 功率阶梯 | 12/15/20/30/46Ω | 300/240/180/120/78W |

## 2. 磁芯

- **PQ35/35，PC95（或同级）**：Ae=196mm²，le=83mm，Ve≈16.3cm³
- Bsat(PC95 @100°C) ≈ **0.41T**，设计余量留一倍以上

## 3. 匝数（1:1，原边 : 副边全绕组）

**Np = 6T，Ns = 6T（中心抽头 3T+3T）**，1:1 匝比。

磁通密度校核（谐振点满压）：

$$B_{pk} = \frac{V_{in}}{4\, N_p\, f_r\, A_e}
= \frac{60}{4\times6\times82.1\text{k}\times196\text{mm}^2} ≈ 0.155\text{T}$$

- 满压扫频到 65kHz：Bpk ≈ 0.196T —— 仍在安全区
- **Bpk 与 k（Lm）无关**：匝数定了，k 只由气隙调

## 4. 气隙（决定 Lm）

目标 **Lm = 26µH**（k = Lm/Lr = 3.2）：

$$A_L = \frac{L_m}{N_p^2} = \frac{26µH}{36} ≈ 722\ \text{nH}/N^2$$

PQ35/35 对应 **中心柱气隙 ≈ 0.32mm**（实测优先，±15% 内可接受；
绕好后用 LCR 在 100kHz 下实测 Lm，垫片微调到目标）。

> 为什么不用更大的 Lm（k=5/40µH）：时域仿真显示满载环流 6.63A(k3.2) vs 5.87A(k5)，
> 折算铜损差仅 **0.1W（300W 上无感）**，而气隙从 0.32mm 压到 0.20mm 更难垫准。
> 1:1 稳压用法下 k 不是敏感参数 → 选好绕的气隙大的那个。

## 5. 线材（82kHz 集肤效应）

- 82.1kHz 集肤深度 δ ≈ **0.23mm** → 必须用 **0.1mm 多股 Litz**（单根 ≤0.2mm 可不用）
- 载流：满载谐振电流 **Irms≈6.6A、Ipk≈10A**（时域仿真）
- 原边 / 副边半绕组截面 **≥ 1.8mm²**：0.1mm Litz **≈200~230 股**（≈1.6~1.8mm²）

## 6. 绕制工艺（三明治，降漏感）

```
副边半绕组 S1（3T）
原边 P（6T）
副边半绕组 S2（3T）
```

- 副边中心抽头两侧各 3T，输出两半绕组串联（跨全输出 1:1）
- **漏感 < 0.5µH**（相对 Lr=8.2µH < 6%）
- 绕制顺序：先 S1 → P → S2，层间绝缘，出线端尽量靠近
- 气隙：中心柱垫 0.32mm 间隙（可磨可垫），装好测 Lm

## 7. 时域仿真验证（`llc_td_verify.m`，2026-08-13）

满载 12Ω @ fr=82.1kHz，Vin=60V：

| 项 | k=3.2（Lm=26µH） | k=5（Lm=40µH） |
|---|---|---|
| Vout | **59.8V** | 59.9V |
| Itank | 6.63Arms | 5.87Arms |
| Imag | 4.11Arms | 2.63Arms |
| Ipk | 9.97A | 8.72A |
| 铜损(11mΩ) | 0.48W | 0.38W |
| 最低可稳压输入(满载) | **39V** | 48V |

功率阶梯 @ fr：12/15/20/30/46Ω → **59.8 / 59.9 / 60.1 / 60.1 / 60.2V**（M=1 全成立）。

## 8. 配套器件注意

- **Lr 电感**：8µH，饱和电流 ≥12A（Ipk≈10A 留裕度），用 PQ26/E 磁芯或外购
- **Cr 电容**：470nF，耐压 ≥100V，纹波电流 ≥10A（满载谐振电流 6.6A rms 经容）
- 两个都不要用现腔 1kW 器件（Z0 差 40 倍，不通用）
