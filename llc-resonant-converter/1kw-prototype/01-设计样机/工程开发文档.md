## 0. 60V 缩尺腔压降根因定论（2026-08-18 实测）

60V 缩尺腔（**Lr=8.2µH / Cr=470nF / Lm=26µH**）测试时"按输出电压算增益异常、效率很低"，排查定论：

- 副边整流前（变压器副边）方波增益**健康**：**fr≈75kHz**（增益=1 实测），80kHz 满摆 60V（M≈1）。
  **不是谐振腔的问题、不是设计的问题、不是器件异常的问题。**
- 唯一根因：整流管 **RHRP860** 正向导通压降（VF 随电流 ~1.0-2.1V/只，两只串 ~2-3V，
  **不是固定 2.1V**）。这颗管子按 **1kW 高压（400V）** 系统选取，**不能直接搬给 60V 缩尺方案**。
- 修复：整流管换 **MBR10100**（10A/100V TO-220AC 肖特基，单管；勿买 CT 双管、勿买 60V 档）。
  验证点：**60V / 80kHz / 40Ω → 预期 ~57-58V**（RHRP860 时 ~55-56V）。

完整记录见 `04-60V缩尺300W/README.md` §11。

## 1. 系统参数

| 参数 | 值 | 说明 |
|---|---|---|
| 拓扑 | 全桥 LLC + 中心抽头全波整流 | 原边 28T，副边全绕组 28T（两个 14T 半绕组），全绕组 1:1 |
| 每路变换比 | 28:14 = 2:1 | 模型 n=2.0 |
| 额定点 | 400V → ±200V / 2.5A / 500W/路 | 跨全 160Ω，每路 80Ω，Q=0.35（设计书） |
| Z0 | 181.5Ω | 特性阻抗 √(Lr/Cr) |
| fr | ~107kHz（设计）／~105kHz（实测增益峰） | |
| Lr / Cr | ~270µH / ~8.2nF | 由 Z0 与 fr 反推 |
| Lm | 2.0mH（设计书 §3.2 k=7.4，LCR 实测一致） | λ = Lr/Lm ≈ 0.135 |
| 输出公式 | Vrail = (Vin/2) × M(fn, Q) | M_max≈1.034（fn≥0.888 频带内，设计书 Q=0.35） |

## 2. 60V 缩尺腔（现腔，Lr=8.2µH / Cr=470nF / Lm=26µH）

- 副边整流前方波增益**正常**：fr≈75kHz（增益=1），80kHz 满摆 60V。
- 唯一压降来源 = 整流管 RHRP860 的 VF（~2-3V，两只串）。
- 修复：换 MBR10100 肖特基。详见 `04-60V缩尺300W/README.md` §11。

## 3. 60V 专用谐振腔（方案A）

> ⚠️ **2026-08-18 更新**：方案A 腔已按实际到手器件落地（Lr=8.2µH/Cr=470nF/Lm=26µH，
> 新变压器 1:1、6T），实测副边增益**正常**（fr≈75kHz，M=1），**无需再换腔**。
> 压降根因=整流管 VF（见 §0）。设计计算、功率阶梯、增益表见 `04-60V缩尺300W/README.md` §3-§6。

## 4. 下一步

1. 购买整流管 **MBR10100**（10A/100V TO-220AC 肖特基，单管；勿买 CT 双管、勿买 60V 档）。
   可顺带买功率电阻做负载：4× 3Ω/100W 串联 = 12Ω 满载（300W@60V，每只 75W），
   或 51Ω/100W ×2 作轻载。
2. 换整流管后验证：**60V / 80kHz / 40Ω → 预期 ~57-58V**（RHRP860 时 ~55-56V）。
