# 1kW 全桥 LLC 工程开发文档

**适用范围：STM32G474 控制、全桥 LLC、双路 ±200V/500W/路（跨全 1kW）样机调试**
**工程位置：`D:\桌面\超级档案\voltage_sampling`（源工程，勿改）／`D:\桌面\超级档案\LLC测试程序`（诊断/测试副本）**

## 1. 系统参数

| 参数 | 值 | 说明 |
|---|---|---|
| 拓扑 | 全桥 LLC + 中心抽头全波整流 | 原边 28T，副边全绕组 28T（两个 14T 半绕组），全绕组 1:1 |
| 每路变换比 | 28:14 = 2:1 | 模型 n=2.0 |
| 额定点 | 400V → ±200V / 2.5A / 500W/路 | 跨全 160Ω，每路 80Ω，Q=0.35（设计书） |
| Z0 | 181.5Ω | 特性阻抗 √(Lr/Cr) |
| fr | ~107kHz（设计）／~105kHz（实测增益峰） | |
| Lr / Cr | ~270µH / ~8.2nF | 由 Z0 与 fr 反推 |
| Lm | 2.0mH（设计书 §3.2 k=7.4，LCR 实测一致） | λ = Lr/Lm ≈ 0.135 |
| 输出公式 | Vrail = (Vin/2) × M(fn, Q) | M_max≈1.034（fn≥0.888 频带内，设计书 Q=0.35） |
