第一课 · 物理直觉：旋钮与秋千

你的 LLC 只有一个旋钮：开关频率 fs

1.1 为什么控制"频率"，不是"占空比"

普通开关电源（Buck、Flyback）用 PWM：固定频率，调占空比 D 改变输出。你的 LLC 不行——全桥必须保持 50% 占空比，靠的是谐振腔把方波变成正弦电流。

谐振腔是 Lr（270µH）串 Cr（8.2nF），它像荡秋千：

  • 推的节奏正好对（fs = 谐振频率 fr = 107kHz）→ 荡得最欢，电压增益 M ≈ 1
  • 推太快（fs > fr）→ 荡不起来，M < 1，输出被压低
  • 推慢一点（fs < fr）→ 荡得更高，M > 1，能升压（但有上限 M_max）

所以控制电压 = 调"推秋千的手速" = 调 fs。这种控制方式叫 PFM（脉冲频率调制）。

⚠️ 方向很重要 fs 升高 → 增益下降 → Vout 下降。也就是说你的"旋钮"是反相的：想让电压上去，频率要往下拧。后面补偿器里的负号就是为了这件事。

1.2 亲手试试：增益曲线

下面这条曲线就是"手速 → 荡幅"关系。拖动 Lm/Lr（励磁电感比，决定升压能力）和负载，看曲线怎么变。

交互 01 · FHA 增益曲线
  • fn = fs/fr：横轴是"频率归一化到谐振点"。fn=1 是谐振点，左边降压区（升压），右边升压区（降压）。
  • M_max：升压的物理上限。看红色标注——满载时只有 1.005，也就是说满负载下想大幅升压是做不到的（第八章详解）。
  • 试试把负载切到 25%：曲线峰值明显抬高（1.243）。负载越轻，越能升压。

1.3 这一课记住三件事

  1. 旋钮 = 开关频率 fs，范围 95–130kHz，额定在 fr = 107kHz。
  2. 反相：fs↑ → Vout↓。
  3. 升压上限 M_max 是物理极限，满载时很小（1.005）。

第二课 · 把电路翻译成传函

被控对象 Gvd(s)：输入 fs，输出 Vout

2.1 从一个"旋钮"到一条"响应曲线"

上一课说"调频率能改电压"，但控制设计需要更精确：拧 1kHz，电压到底变多少？变多快？这就是传递函数 Gvd(s) 回答的问题。

在数学上，你的 LLC 从 fs 到 Vout 的小信号模型是三阶的：

Gvd(s) = K_f · (1 + s/ωz_lm) / (1 + s/ωp_out) · (1 + s/(ωrQr) + s²/ωr²)

不用被公式吓到——它只是三个"性格特征"的乘积，每个对应一个物理东西：

因子数值物理含义影响
K_f（直流增益）-0.505 V/kHz拧 1kHz 频率，输出稳态变 0.51V决定"旋钮的力气"
输出极点 fp_out19.9 HzCo=100µF × 负载 80Ω，τ=8ms（满载值；轻载 Rload 变大，极点左移）决定"响应多慢"
谐振极点 fr107 kHz谐振腔的固有振荡离得远，影响小

K_f 为什么是负的？因为它继承"反相"：fs↑ → Vout↓，所以灵敏度是负数。后面所有设计都带着这个负号。

输出极点 19.9Hz 从哪来？输出电容要充放电，电荷变化要经过负载电阻，这构成一个一阶低通，时间常数 τ = Rload·Co = 80Ω × 100µF = 8ms，对应极点频率 1/(2πτ) ≈ 19.9Hz。含义：你拧了旋钮，电压不会立刻到，要"充电 8ms 量级"。

2.2 极点到底怎么决定"快慢"——亲手看

极点位置是理解一切的关键。下面左边是 s 平面，右边是对应的二阶系统阶跃响应。拖动 ζ（阻尼）和 ωn（自然频率）感受：

交互 02 · 极点位置 ↔ 阶跃响应
  • 离虚轴越远（ωn 大）→ 振荡越快、峰越早。
  • ζ 越小（极点越靠虚轴）→ 振荡越剧烈、衰减越慢。
  • ζ ≥ 1 → 完全不振荡（过阻尼）。
  • 我们的被控对象在输出极点处 ζ=1（实极点，不振荡，慢），在谐振极点处 ζ≈1/2（会振荡，但 107kHz 太远，环路感觉不到）。
🧠 结论 被控对象 Gvd(s) = 一个增益 K_f + 一个慢极点(19.9Hz) + 一个很远的谐振极点(107kHz)。 环路设计只要对付 K_f 和那个慢极点就够了——这就是为什么穿越频率敢设在 2kHz（离 107kHz 有 50 倍距离）。

第三课 · 负反馈与稳态误差

为什么一定要闭环，为什么一定要积分

3.1 开环为什么不行

如果不用反馈：把频率固定死（比如开环 107kHz），那么输出 = 增益 × 输入。但输入电压在 360–440V 之间变化，负载也在变——输出电压会跟着飘，永远到不了精确的 200V。开环是"盲拧"。
负反馈的做法：量到实际 Vout，跟目标 200V 比出偏差 err，再按偏差去拧旋钮。这样不管什么扰动，只要偏差不为零，系统就会一直纠正，直到偏差消失。

vref ─(+)──► 补偿器 C(z) ── fs ──► 对象 Gvd(s) ──► Vout   ▲                              │
  │              ▲                        │
err = vref − vmeas   │          （采样 vmeas）

3.2 关键一环：为什么必须"积分"

假设只用纯比例：fs = fr + Kp·err。电压偏低一点 → 频率往下一点 → 电压回升一点，但回升的幅度恰好让 err 变小、纠正减弱……最终停在一个还有残差的平衡点，永远差一点（叫稳态误差）。因为 Kp·err 需要一个非零的 err 才能撑着。

积分项把历史误差累加起来：只要 err 不为零，累加值就一直增长，输出的修正就一直加大，直到把 err 压到零。所以：积分 = 精确消除稳态误差。

在传函上，"积分"就是分母里那个 s（1/s 对直流有无限增益）。你的补偿器长这样：

C(s) = Kc · (1 + s/ωz) / s · (1 + s/ωp)

分母那个 s 就是积分。它在 0Hz 给出无限大增益 → 输出精确等于 200.000V，不差一毫。

🔑 一句话 反馈保证"方向对"，积分保证"误差归零"，剩下的问题就是"多快、稳不稳"——那是下一课。

第四课 · Bode 图与稳定性

穿越频率、相位裕度：环路的"体检指标"

4.1 Bode 图在说什么

把开环传递函数 L(s) = C(s)·Gvd(s) 在各个频率下求一遍：放大多少倍（增益 dB）、相位挪多少（相位 °），画出来就是 Bode 图。它回答两个问题：

  • 这个频率的扰动，环路能纠得多用力？→ 看增益曲线
  • 环路对这个扰动，是及时反应还是反应过头？→ 看相位曲线

4.2 两个体检指标

指标物理含义设计值
穿越频率 fco增益 = 1（0dB）的频率。环路能纠正多快的扰动。≈ 响应速度。~2 kHz
相位裕度 PM在 fco 处，相位离 -180°（振荡线）还剩多少。剩得越多越稳。71.0°

直觉：骑自行车。你每偏离直线一点就往回扶一下——但如果你"扶"的增益太大（反应过头），加上 2 拍延迟，就会左右蛇形（振荡）；如果增益太小，就压不住风（扰动）。相位裕度就是你心里默数的那一拍，还能不能来得及修正。PM ≤ 0 → 振荡/发散。

⚡ 稳定性铁律 fco 处相位若低于 -180°，环路就变成正反馈 → 电压来回冲 → 炸。 PM 就是"离这条线还差多远"。PM ≥ 45° 是底线，我们留到 70°——多留的 25° 是给"吃相位"的因素准备的：采样保持+一拍延迟（约 10°）、谐振模型简化、以及 Lm/Co 实测与设计值的偏差。留足了，最坏情况（参数离散）也不振荡。

第五课 · 补偿器设计

Type II：积分 + 一个零点 + 一个高频极点，各治一个病

5.1 补偿器 = 按对象的"性格"配眼镜

被控对象有毛病（慢极点、噪声敏感），补偿器就对症下药。你的 Type II 补偿器三个环节，各治一个：

环节位置治什么类比
积分（分母 s）低频消除稳态误差，精确 200V盯死车道不跑偏
零点20 Hz抵消 19.9Hz 输出极点，把相位坑填平 → 才能提穿越频率近视散光各配一片镜片
高频极点10 kHz压掉 107kHz 开关纹波和采样噪声屏蔽高频杂音

为什么要"零点去抵输出极点"？因为那个 19.9Hz 极点让相位往 -90° 掉，如果不抵消，环路在低频就亏相位，穿越频率只能做得很低（响应慢）。零点在它附近，把相位坑补回来，才允许 fco 提到 2kHz。

5.2 亲手试试：把补偿器拆了再装上

回到 Bode 设计台，这次 三个滑杆都动：

  • 零点拖离 20Hz（比如拖到 1Hz 或 200Hz）→ 看相位曲线在 fco 附近的"坑"回来，PM 掉。
  • 高频极点拖到 1kHz → 看它把 fco 拽低、PM 掉。
  • K_c 拉大 → fco 右移逼近谐振区，PM 掉。

设计目标：fco≈2kHz 处 PM ≥ 45°。你会发现"设计好的补偿器"就是三个参数的精确搭配——这就是配眼镜。

🧪 设计出来的指标（连续域） Kc = -2.4922×10⁷，零点 20Hz，极点 10kHz
fco ≈ 1960 Hz，PM ≈ 80.9°，GM ≈ 43.3 dB
穿越频率只有开关频率（107kHz）的 1/50——这是刻意的：环路只"看平均"，不跟开关纹波较劲。

第六课 · 数字化：从传函到代码

每开关周期看一眼、算一次、动一次手

6.1 数字控制器失去了什么

模拟控制器是"一直盯着"的；数字控制器是每隔 9.35µs（1/107kHz）眨一眼：采样 → 算偏差 → 跑差分方程 → 写频率寄存器。代价有二：

  • 采样（ZOH 保持）：本来连续的信号变成台阶。
  • 一拍计算延迟：这一拍看到的电压，下一拍才轮到修正。

两者合起来，在 2kHz 穿越处吃掉约 10° 相位。所以连续域 PM 80.9°，离散后 71.0°——这就是为什么设计要"离散化后再验一遍"。

6.2 Tustin：把 s 域翻译成 z 域

补偿器是连续传函 C(s)，单片机不能算 s，要用一个近似把连续变成离散差分方程。常用 Tustin 变换：

s = (2/Ts) · (z − 1)/(z + 1)，  Ts = 1/fr = 9.35µs

代入 C(s) 展开，得到 2p2z（两个零点两个极点）的标准形式，最后变成三行差分方程（直接 II 型）：

// 每开关周期调用一次。err = vref − vmeas
w  = b0*err + x1;         // w = 本拍修正量
x1 = b1*err - a1*w + x2;  // x1, x2 是环路的"记忆"
x2 = b2*err - a2*w;
fs = clamp(fr + w, 95k, 130k);   // 频率指令，带回钳位

x1, x2 存的是历史误差与输出的加权记忆——它们让"积分"存在（这就是上一课那个积分在数字世界的落地）。clamp 是硬限制：95–130kHz，防止频率出界，也防止积分越积越大（抗饱和）。

6.3 系数怎么来

这套系数（b0…a2）不是你手算的，是 llc_loop_design.m 自动算出来的：设计 C(s) → Tustin 离散 → 提取系数 → 写进 llc_ctrl.h。你要改的是参数（Lm、Co），不是系数。

#define LC_B0  -45051.86f
#define LC_B1  -52.90f
#define LC_B2  44998.96f
#define LC_A1  -1.54594f
#define LC_A2  0.54594f
⚠️ 负号别删 b0、b1 是负的，因为整个对象是反相的（fs↑→Vout↓）。删掉负号 = 正反馈 = 上电即炸。

第八课 · 答疑：那些"为什么"

把你设计里真正会问出口的问题一次答完

8.1 为什么满载 + 360V 时 ±200V 会稳不住？

因为谐振腔的物理极限：360V 输入要得到 200V 输出，需要增益 M = 400/360 = 1.111。但满载时阻尼很大（Q=1.4），增益峰值只有 M_max = 1.005（回 01 课的曲线看看）。物理上给不出 1.111，所以控制器把旋钮拧到底（fs_min=95kHz）也没用，输出随输入跌落。这是硬件问题，不是环路问题。要改得调 Lm/Lr 或 Lr/Cr（降 Q），让秋千能荡更高——代价是 ZVS 裕量和轻载效率。

8.2 K_f 会随负载变吗？——一个被纠正的旧说法

早期版本用过不完整的 FHA 公式 + 未实测的 Lm 假设（m=5），K_f 偏差近 1.5 倍。用标准 FHA 公式 + LCR 实测 Lm=2mH（m=7.4）核对后：fn=1 处增益曲线斜率 dM/dfn = -2/m，与负载 Q 无关，所以 K_f 恒为 -0.505 V/kHz。真正随负载变的是输出极点：轻载时 Rload 变大，fp_out = 1/(2π·Rload·Co) 左移（50% → 10Hz）。极点左移让低频增益变平、fco 下移，PM 反而更高（50% 负载 PM 84.8°，25% 负载 85.9°）。结论反过来了：负载越轻，环路越稳——"一个增益发四个负载都稳"这件事比原来想的更省心。

8.3 为什么穿越频率敢设在 2kHz 而不是 20kHz？

三个理由：① 离开关频率 107kHz 有 50 倍远，环路"看平均不看纹波"，模型里的谐振极点影响可忽略（只有 12°）；② 2kHz 已远高于输出极点 19.9Hz，动态足够快；③ 再快就要跟开关纹波和采样噪声较劲，还会逼近采样保持 + 一拍延迟带来的相位损失上限。

8.4 为什么 ADC 采样必须快？

设计是按每开关周期控制做的（Ts = 9.35µs）。如果采样要 60µs（现在的 640 周期采样），一个控制周期都做不完，等于把控制率降到 1/6，环路带宽大打折扣，还会引入额外延迟。实测前必须把 ADC 采样缩短到 ≤4.5µs。

8.5 为什么 Lm 必须实测？

Lm 进 K_f 的公式（K_f ∝ -2/m，m=Lm/Lr），直接决定增益标定；还决定 M_max（升压能力）和 fm。设计最初按 Lm=5×Lr 假设，LCR 表实测原边电感 Lm=2mH（m=7.4）后，K_f 从 -0.748 修正为 -0.505 V/kHz（差 1.48 倍）——这就是本次全线改系数、改教程的根因。用 LCR 表量原边电感，改完重跑 llc_loop_design.m，系数自动更新。

Q1：你的 LLC 想提高输出电压，应该把开关频率 fs 调高还是调低？
调低。
fs 低于 fr 进入升压区，增益 M > 1。旋钮是反相的：fs↑→Vout↓，所以升压要 fs↓。
Q2：满载 360V 输入时，为什么调频也救不回 ±200V？
谐振腔增益有物理上限 M_max=1.005，而 360V 需要 1.111。
控制器把频率压到 fs_min 就到底了（低于 fn≈0.95 增益反而回落），剩下的缺口是谐振腔给不出来的——这是硬件极限，要改 Lm/Lr 或 Lr/Cr。
Q3：补偿器里的"零点在 20Hz"是干什么的？去掉会怎样？
抵消被控对象 19.9Hz 的输出极点，把低频相位坑补平。
不去掉的话相位亏得多，穿越频率只能做低、响应变慢。回到 05 课的 Bode 设计台把零点拖到 1Hz，看 PM 掉多少。
Q4：轻载时环路更危险，对吗？
反了，轻载反而更稳。
K_f 与负载无关（-0.505 V/kHz）。轻载时输出极点左移，fco 下移、PM 上升（50% 负载 PM 84.8°，25% 负载 85.9°）。最坏工况是满载，所以设计按满载整定即可。
Q5：离散化把 PM 从 80.9° 变成 71.0°，那 10° 去哪了？
采样保持 + 一拍计算延迟。
数字控制器每 9.35µs 才看一次、下一拍才动手，在 2kHz 穿越处大约损失 10°。这就是"离散后要重验一遍裕度"的原因。
