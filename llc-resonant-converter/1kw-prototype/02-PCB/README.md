## 主功率板（Gerber 实测）

1kW 全桥 LLC 变换器主板。

| 项目 | 数据 |
|---|---|
| 层数 | **2 层**（Top + Bottom，双面焊盘） |
| 过孔 | **595**（0.305mm / 0.381mm） |
| 镀通孔 PTH | **726**（0.305–1.9mm 共 22 种孔径） |
| 非镀通孔 NPTH | **2**（1.3mm，安装孔） |
| 组装 | 双面：Top/Bottom 丝印 + 阻焊 + 锡膏 |
| 生产测试 | **飞针测试通过**（`FlyingProbeTesting.json`） |
| 工具链 | 嘉立创 EDA Pro v3.2.174 |
