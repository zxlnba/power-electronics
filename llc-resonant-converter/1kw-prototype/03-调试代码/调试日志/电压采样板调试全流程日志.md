## 一、硬件设计确认阶段(8/2 ~ 8/4)

### 1.1 需求
- 测量两路母线电压:一路最高 **+200V**,一路最高 **-200V**(0~200V / 0~-200V,绝对值基本相同,除极端不平衡负载)
- 最终信号给 **STM32G474RBT6**

### 1.2 信号链设计
```
母线电压 → 电阻分压 → AMC1350(隔离运放) → 差分运放(TLV9002) → VADC → STM32 PA0/PA1
```
- **AMC1350DWV(R)**:隔离放大器,隔离高压侧与 MCU 侧
- **TLV9002**:差分放大
- 传递函数(反相):
  ```
  VADC = VCM - K × Vrail
  Vrail = (VCM - VADC) / K
  ```
- 设计要点:串阻 1k + 反馈 7.5k;VCM 理论 = 5V × 10k/(20k+10k) = 1.667V

### 1.3 关键器件参数决策
| 参数 | 决策 | 说明 |
|---|---|---|
| 反馈电阻 | 7.5k(实测值) | 9.1k/7.5k 选 7.5k |
| AMC 输出串阻 | 1k | 与反馈 7.5k 不串联影响增益(对称理解) |
| VCM 滤波电容 | 10µF 改值 | 找不到 10µF |
| 测试范围 | 先 30-60V 验证 | 再上高压 |

### 1.4 换芯片后的实测数据(0V 输入基线验证)
输入电压 → VADC 实测:

| Vrail | VADC |
|---|---|
| 0V | 1.645V |
| 5V | 1.612V |
| 10V | 1.568V |
| 15V | 1.539V |
| 20V | 1.507V |
| 30V | 1.443V |
| 35V | 1.408V |
| 40V | 1.378V |
| 45V | 1.345V |
| 50V | 1.314V |
| 55V | 1.282V |
| 60V | 1.249V |

**推导结论**:
- 输入增大 → VADC 减小 = **反相**,符合设计
- **增益 K = (1.645 - 1.249) / 60 = 0.0066 V/V**
- **基线 VCM = 1.645V**(0V 输入时的 VADC)

### 1.5 硬件踩过的坑
- **AMC1350 芯片不良**:运放 2/3 脚虚短失效(实测 0.2V 差)、输出起点 2V、VOUTP/VOUTN 电压对不上 → **更换芯片后恢复正常**
- 供电异常:5V 轨实测仅 4.58V(偏低)→ 影响 VCM 精度

## 三、固件 ADC 排障(8/5,本次接管核心)

### 3.1 症状
- OLED 显示 RAW **恒为 0**,错误码 **E=4**(HAL_ADC_Start/Poll 失败)

### 3.2 排查过程(按步骤)

**① 确认芯片与电源状态(诊断固件)**
- DEV_ID = **0x469** → 真 STM32G474 ✅
- ADC1->CR = 0x10000000 → 稳压器开、深功耗关 ✅
- ADRDY 手动使能 <1ms 就绪 → 时钟/供电无根本问题 ✅

**② 根因一:ADC 时钟配置(E=4 的直接原因)**
- 原配置:PLL + 同步时钟 DIV4 → **ADC 时钟 42.5MHz,ADRDY 不置位 → Start 超时**
- 修复:改 `RCC_ADC12CLKSOURCE_SYSCLK` + `ADC_CLOCK_ASYNC_DIV16`
- 结果:**fADC = 170/16 = 10.6MHz → E=0,转换正常**

**③ 根因二:RAW 显示 bug**
- 现象:ADC 已正常转换(E=0),但 OLED RAW 仍是 0
- 根因:`vs_read_rails_avg()` **从不更新 `g_raw_pos`**(只有从不调用的 `vs_read_rails()` 才更新)→ RAW 显示一直是假 0
- 修复:avg 函数补上 `g_raw_pos = sum1/samples`

**④ 根因三:参考电压错(-30V 偏移)**
- 现象:0V 输入时 V+ 显示 -27 ~ -31V
- 计算反推:RAW=2292 对应 VADC=1.846V,而实测引脚 1.645V → 实际 VDDA ≈ 2.94V(固件按 3.3V 算)
- 尝试 VREFINT 校准:临时重配置方式失败(R=0),改第 3 通道方式后供电仍不稳
- **最终根因:板子 3.3V 供电实际只有 2.7-2.8V 且浮动**

**⑤ 根因四:供电不稳定(硬件,非固件)**
- 万用表实测 VDDA **2.7-2.8V 且持续浮动**
- 导致:每次上电读数不同、读数漂移(0→11V)、加电压不准
- 固件能补偿"参考电压不对但稳定",**无法补偿浮动供电**
- **解决:更换为稳定供电(3.3V)**

### 3.3 最终固件配置(标准 3.3V 版)
> ⚠️ 该配置为 **08-05 状态**，已被第五节（十点标定 1.627/0.0058 + VREFINT 归一化 + 0V 慢速校零）取代，仅作历史存档。
```
ADC 时钟源:  RCC_ADC12CLKSOURCE_SYSCLK
预分频:      ADC_CLOCK_ASYNC_DIV16 → fADC = 10.6MHz
分辨率:      12bit
采样时间:    640 周期(60µs,平均 LLC 开关纹波)
通道:        PA0 = ADC1_IN1(正轨), PA1 = ADC1_IN2(负轨)
参考电压:    VS_ADC_VREF = 3.3V(标准)
基线:        VS_VCM_DEF = 1.645V(0V 输入实测)
增益:        VS_K = 0.0066
平均次数:    64 次/100ms
显示平滑:    0.7×旧 + 0.3×新(~0.8s 响应)
```

### 3.4 显示响应慢问题
- 现象:浮空 100V → 接 0V 采样板,需 ~5s 才降完
- 定位:**是显示 EMA 平滑慢,不是采样慢**(采样仅 ~8ms/次,每 100ms 更新)
  - 原 0.95/0.05 时间常数 = 20 次更新 = 2s,95% 稳定需 ~5.8s
- 修复:0.95/0.05 → **0.7/0.3**(~0.8s 稳定)

## 四、关键结论与经验

1. **先确认电源,再查固件**:本次 60% 的"固件问题"其实是供电问题(2.7-2.8V 参考电压错)。量 VDDA 是第一件事。
2. **E=4(ADRDY 超时)≠ 硬件坏**:G4 上很可能是 ADC 时钟源/分频配置问题,优先查 `RCC_CCIPR` 的 ADC12SEL 和 `ADC12_COMMON->CCR` 的 CKMODE/PRESC。
3. **显示恒 0 要先查显示路径**:`g_raw_pos` 这类全局变量是否真的被实际调用的函数更新了。
4. **LLC 板采样噪声**:采样窗口短(1.2µs)会抓到 107kHz 开关纹波的不同相位 → 用长采样时间(640 周期 ≈ 6 个开关周期)平均。
5. **稳定供电下应回归标准配置**:诊断/校准代码在稳定后可移除,保留必要的修复即可。

## 五、LLC 读数精确化（08-05 ~ 08-10 追加，诊断工程 `LLC_DIAG_OLEDraw_95k固定`）

LLC 低压测试阶段把电压读数从"能动"追到"准确稳定 ±0.1V"的完整过程与结论。全程只改诊断副本，源工程 `voltage_sampling`（SWEEP=1 开环扫频 + legacy 宏 bug）保持原样未动。

### 5.1 十点标定（2026-08-10，替换第三节的 3.3V 版旧值）
- 万用表量采样端子、VADC 量 ADC 引脚，10 点拟合。
- 结论：两路均**反相**（Vrail↑→VADC↓），**两路 K 均 = 0.0058 V/V**，0V 基线 ≈ 1.626V（±11.64V 对称中心 1.6265 印证）。
- 旧值 `VCM=1.645/K=0.0066` 在 8V 处差 ~2.3V（"1–2V 偏差"根因）；早期"K+=0.0056/K-=0.0060"是基线取 1.625 造成的假象。
- 现 `VS_VCM_DEF=1.627`（固定标定值）作起点 + 0V 慢速校零（见 5.6）。

### 5.2 VDDA 漂/抖 → VREFINT 归一化（勿用绝对参考）
- VDDA 实测 3.183V（08-09）→ ≈3.16V（08-10），且抖动 ±0.3% → 固定参考读数跳 0.8V（9.3↔10.1）。
- **VREFINT 归一化**：`g_vref = 3.0×VREFINT_CAL/VREFINT_counts`（32 次累加 + 0.25 低通），`VADC = counts×g_vref/4096`。ratio 抵消 ±1% 容差（出厂标定与实测同载 VREFINT），漂移/抖动自动消除。
- 废弃路径：VREFINT 当**绝对**参考（±1% 容差 ÷ K ≈ ×88 → 0V 偏 2V）；固定 VCM 电压公式（参考漂 0.02V → 偏 2V）。

### 5.3 采样结构（每 REP 单通道交替，G4 SQR1 要点）
- ADC1 由 REP 中断 `adc1_sample_isr` 独占（无忙等），每 3 REP 轮询 PA0→PA1→VREFINT(CH18)。
- ⚠️ G4 SQR1：L[3:0] 在 bit0-3、SQ1[4:0] 在 bit6-10。写 `0x1`=L=1 仍是双通道扫描（OVR 挂起抑制 EOC）。必须 `(ch<<6)`：CH1=`1U<<6`、CH2=`2U<<6`、CH18=`18U<<6`。
- CH18 采样时间提到 47.5cyc（VREFINT 源阻抗高）；`ADC12_COMMON->CCR` 的 `VREFEN` 必须置位，否则 CH18 读到浮空杂散值。

### 5.4 显示慢低通（344ms）
- 残余 ±1V 跳 = >10Hz 前端测量噪声落在 counts（万用表内部积分平均掉，ADC 没平均），归一化治不了参考之外的噪声。
- `g_vpos = s_vp_disp += (vp−s_vp_disp)/32768` per REP ≈ 344ms：50Hz 压 ~108× → ±1V → ±0.01V；真实变化 ~1.6s 跟上。vmeas 快路径留给闭环另行滤波。

### 5.5 接板 0V→13V、上电随机 40-50V：根因 = 抓基线时机不可靠 + 突变拒绝锁死
- 前端（AMC1350 隔离运放 + 隔离电源）上电需建立时间，早抓基线抓到爬升中随机值；突变拒绝（±25 counts）把错误基线锁死成永久零位（真实样本差>25 全被丢弃）→ 每次上电读不同几十V。
- 修复：**删除突变拒绝**，改纯指数低通 α=1/16；抓的计数只作平滑起步（0.5ms 自收敛，异常回退名义值）。
- **关键发现**：前端 0V 共模**每次上电可能不同**（实测 1.626V 与 2.15V 两态），还会起步漂/热漂。

### 5.6 最终方案：0V 慢速校零（hex `diag_0V慢速校零_10点_95k.hex`，md5 2f9a37b7）
- 固定 1.627V 追不上逐次上电共模漂移（实测落 1.621V → 起步偏 0.8~1.1V、带载后 V+ 读 10/V- 读 −8，真实 ±9.13；共模偏 ~5mV ≈ 读偏 ~1V）。
- **0V 慢速校零**：门控 = `|vmeas|` 慢平均 < 0.5V。vmeas=(vp−vn)/2 中零点偏移**精确抵消** → 0V 时门恒开（即使显示偏 ~1V）、一有输出电压立即关。门内零点慢速拉向当前真实共模（=当前 VADC），τ≈0.5s 无跳变；跟随逐次上电/起步/热漂，一出压冻结。
- 与已排除的"上电抓基线"本质不同：那个开机瞬间抓一次（爬升中随机值+锁死），这个只确认 0V 才连续慢速跟随，不可能锁死错误值。
- **vmeas 免疫共模偏移**：`vmeas=(V+−V−)/2` 的稳压精度一直是对的（±9.13 是 vmeas 保证的），偏的只是显示绝对值。
