# 20kW 全桥 LLC 谐振变换器 — 纸面设计

## 设计规格

| 参数 | 数值 |
|---|---|
| 额定输入 | 800V DC（范围 750–820V） |
| 输出架构 | ±400V 双输出 / 800V 单输出（可切换） |
| 额定功率 | 20kW |
| 并联能力 | ≥10 台模块并联，无主从均流 |
| 谐振频率 | 107kHz |
| 效率目标 | ≥97%（满载） |

## 1. 拓扑与工作原理

```
800V DC → 全桥逆变 (SiC MOSFET×4) → LLC 谐振腔 (Lr/Cr/Lm) → 高频变压器 → 全桥整流 → ±400V 双输出
```

- **全桥逆变**：4 颗 SiC MOSFET 构成 H 桥，占空比 50% 互补驱动，死区时间实现 ZVS
- **LLC 谐振腔**：谐振电感 Lr + 谐振电容 Cr + 励磁电感 Lm
- **高频变压器**：原边串联谐振腔，副边中心抽头输出，变比 n:1:1
- **整流输出**：副边全桥整流（SiC SBD），分压电容中点接地实现 ±400V 双输出

### 工作原理

LLC 通过变频控制利用谐振网络增益-频率特性调压：

- **谐振频率 fr**：`fr = 1/(2π√(Lr·Cr)) = 107kHz`
- **第二谐振频率 fm**：`fm = 1/(2π√((Lr+Lm)·Cr))`
- 额定工作时 fs ≈ fr，增益 ≈ 1；低输入时 fs < fr 升压；轻载时 fs > fr 降压
- **原边 ZVS**：励磁电流在死区时间内对结电容充放电，实现全桥 ZVS 开通
- **副边 ZCS**：fs ≤ fr 时整流二极管自然关断，无反向恢复

## 2. FHA 谐振腔参数设计

### 2.1 基波等效模型

采用基波近似法 (First Harmonic Approximation)：

1. 逆变输出方波 → 基波：`Vin_FHA = (4/π)·Vin·sin(ωt)`
2. 谐振网络 → Lr、Cr、Lm 线性网络
3. 副边负载 → 等效交流电阻：`Rac = (8n²/π²)·Rload`

**电压增益传递函数**：

```
M(fn, Q, k) = | fn²·(k-1) / ( (fn²-1)·k + j·fn·(fn²-1)·Q·k·(k-1) ) |

其中：
  fn = fs/fr        — 归一化频率
  Q = √(Lr/Cr)/Rac  — 品质因数
  k = (Lr+Lm)/Lr    — 电感比
```

### 2.2 参数选取

| 参数 | 符号 | 数值 | 选取依据 |
|---|---|---|---|
| 谐振频率 | fr | 107kHz | 兼顾开关损耗与磁件体积 |
| 电感比 | k | ≈6 | k 大缩小调频范围但增加环流，折中 |
| 品质因数 | Q | 0.3–0.5 | Q 大增峰值增益但降效率，满载 Qmax=0.4 |
| 谐振电容 | Cr | 44nF | `Cr = 1/(2π·fr·Q·Rac)` |
| 谐振电感 | Lr | 50μH | `Lr = 1/((2πfr)²·Cr)` |
| 励磁电感 | Lm | 300μH | `Lm = (k-1)·Lr`，k=6 |

### 2.3 ZVS 边界校核

```
Im_pk ≥ (2·Coss·Vin) / td

  Im_pk = Vin/(4·Lm·fr)  — 励磁电流峰值
  Coss ≈ 150pF             — SiC MOSFET 等效输出电容（800V 偏压）
  td ≈ 200ns               — 死区时间
```

校核结果：全输入电压范围、20%–100% 负载均满足 ZVS，裕量 ≥30%。

## 3. SiC 功率器件选型与损耗

### 3.1 选型分析

| 考虑因素 | 分析 |
|---|---|
| 电压应力 | 800V 直流母线 + 30% 尖峰裕量 → 1200V 器件 |
| 电流应力 | 20kW/800V = 25A 平均，谐振峰值约 √2 倍 → ≥35A 峰值 |
| 导通电阻 | SiC 1200V Rds(on) 典型 15–40mΩ（25°C），按 125°C 取 1.8–2.0 倍 |
| 开关特性 | SiC 关断极快 (tf<20ns)，关断损耗大幅低于 Si IGBT |
| ZVS 兼容 | Coss 小有利于 ZVS 实现，降低死区时间要求 |

### 3.2 全工况损耗分解

| 损耗项 | 满载估算 | 说明 |
|---|---|---|
| 原边 SiC MOSFET ×4 | ~120W | 导通 + 关断（ZVS 开通近似零） |
| 副边整流 SiC SBD | ~80W | 导通损耗（零反向恢复） |
| 变压器 | ~60W | Steinmetz 铁损 + 铜损（含趋肤/邻近效应） |
| 谐振电感 | ~30W | 铁损 + 铜损 |
| 辅助 + 其他 | ~30W | 控制供电、采样等 |
| **总损耗** | **~320W** | |
| **满载效率** | **98.4%** | |

## 5. 控制策略

### 双闭环变频控制

```
Vref → [电压PI] → Iref → [电流PI] → fs → [PFM发生器] → 全桥驱动
         ↑                          ↑
       Vout采样                   Ires采样
```

- **电压外环 + 电流内环**：输出稳压 + 谐振电流限幅
- **PFM 调制**：固定 50% 占空比互补 + 死区，仅调频率

### 无主从并联均流

**母线峰值电流法**：各模块在直流母线上注入与自身电流成比例的高频信号 → 检测合成信号提取均值 → 调节自身使偏差归零。无中央控制器，单模块故障不影响其余。

## 7. PCB 设计

Gerber 文件位于 `pcb/` 目录。
