# 全桥 LLC 谐振变换器

面向数据中心高压直流供电场景的 20kW 单向全桥 LLC 谐振变换器。

- **竞赛**：高校电气电子工程创新大赛 省三等奖
- **团队**：周俊杰 + 袁泽桂，指导教师：许俊云

---

项目分为两个阶段：

| 阶段 | 目录 | 内容 |
|---|---|---|
| **20kW 纸面设计** | [`20kw-design/`](./20kw-design/) | FHA 谐振腔设计、SiC 选型与损耗、PLECS 仿真 |
| **1kW 原理样机** | [`1kw-prototype/`](./1kw-prototype/) | 原理图设计、PCB、电压采样板、实物调试 |
