# 全桥 LLC 谐振变换器

## 概述

面向数据中心高压直流供电场景，设计 20kW 单向全桥 LLC 谐振变换器。

- **竞赛**：高校电气电子工程创新大赛 省三等奖
- **团队**：2 人（周俊杰 + 袁泽桂），指导教师：许俊云
- **时间**：2024.07 – 至今

## 设计规格

| 参数 | 数值 |
|---|---|
| 额定输入 | 800V DC |
| 输出架构 | ±400V 双输出 / 800V 单输出（可切换） |
| 额定功率 | 20kW |
| 并联能力 | 支持 10 台以上模块并联 |
| 谐振频率 | 107kHz |
| 变压器磁芯 | PC95 材质 |

## 设计工作

### 谐振腔参数设计
- 基于 FHA 基波分析法完成 Lr / Cr / Lm 参数设计
- 校核 750–820V 宽输入范围全负载 ZVS 软开关边界
- 完成 SiC 功率器件选型、应力校核与全工况损耗计算

### 控制策略
- 双闭环变频控制（电压外环 + 电流内环）
- 母线峰值电流法无主从均流策略
- 基于 STM32 实现：ADC 采样、PI 控制、PWM 生成、串口通信

### 仿真验证 (PLECS)
- 单模块稳态 / 动态 / 不平衡负载 / 架构切换
- 5 台并联 + 10 台并联 + 均流策略验证
- 仿真额定效率 98.8%，10 台并联均流偏差 < 2%

### 样机验证
- 完成 20kW 主电路原理图绘制
- 1kW 缩比样机搭建与实测
- 定位寄生参数引起的开关尖峰与驱动保护不足，完成 PCB 改版方案
