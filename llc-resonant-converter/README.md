# 全桥 LLC 谐振变换器

面向数据中心高压直流供电场景的 20kW 单向全桥 LLC 谐振变换器设计。

- **竞赛**：高校电气电子工程创新大赛 省三等奖
- **团队**：周俊杰 + 袁泽桂，指导教师：许俊云
- **时间**：2024.07 – 至今

## 设计规格

| 参数 | 数值 |
|---|---|
| 额定输入 | 800V DC（范围 750–820V） |
| 输出架构 | ±400V 双输出 / 800V 单输出（可切换） |
| 额定功率 | 20kW |
| 并联能力 | ≥10 台模块并联，无主从均流 |
| 谐振频率 | 107kHz |
| 效率目标 | ≥97%（满载） |

## 1. 拓扑与工作原理

### 1.1 拓扑结构

采用全桥 LLC 谐振变换器，由以下环节组成：

```
800V DC → 全桥逆变 (SiC MOSFET×4) → LLC 谐振腔 (Lr/Cr/Lm) → 高频变压器 → 全桥整流 → ±400V 双输出
```

- **全桥逆变**：4 颗 SiC MOSFET 构成 H 桥，占空比 50% 互补驱动，死区时间实现 ZVS
- **LLC 谐振腔**：谐振电感 Lr + 谐振电容 Cr + 励磁电感 Lm
- **高频变压器**：原边串联谐振腔，副边中心抽头输出，变比 n:1:1
- **整流输出**：副边全桥整流（SiC SBD），分压电容中点接地实现 ±400V 双输出

### 1.2 工作原理

LLC 工作在变频控制下，利用谐振网络的增益-频率特性实现调压：

- **谐振频率 fr**：由 Lr 和 Cr 决定，`fr = 1/(2π√(Lr·Cr)) = 107kHz`
- **第二谐振频率 fm**：由 (Lr+Lm) 和 Cr 决定，`fm = 1/(2π√((Lr+Lm)·Cr))`
- 额定工作时开关频率 fs ≈ fr，增益 ≈ 1
- 输入电压跌落或重载时 fs < fr，工作于升压区（Boost 区）
- 轻载或高输入时 fs > fr，工作于降压区（Buck 区）

**ZVS 软开关**：LLC 通过励磁电流在死区时间内对 MOSFET 结电容充放电，实现原边全桥 ZVS 开通，开关损耗极低。

**副边 ZCS**：当 fs ≤ fr 时，副边整流二极管自然关断，无反向恢复损耗。

## 2. 谐振腔参数设计

### 2.1 FHA 基波分析

采用基波近似法 (First Harmonic Approximation) 对 LLC 谐振腔建模：

1. **逆变输出方波**分解为基波：`Vin_FHA = (4/π)·Vin·sin(ωt)`
2. **谐振网络**简化为 Lr、Cr、Lm 的线性网络
3. **副边负载**折合到原边的等效交流电阻：`Rac = (8n²/π²)·Rload`

由此得到 LLC 谐振腔的**电压增益传递函数**：

```
M(fn, Q, k) = | fn²·(k-1) / ( (fn²-1)·k + j·fn·(fn²-1)·Q·k·(k-1) ) |

其中：
  fn = fs/fr        — 归一化频率
  Q = √(Lr/Cr)/Rac  — 品质因数
  k = (Lr+Lm)/Lr    — 电感比
```

### 2.2 参数选取

| 参数 | 符号 | 数值 | 选取依据 |
|---|---|---|---|
| 谐振频率 | fr | 107kHz | 兼顾开关损耗与磁件体积 |
| 电感比 | k | 5–8 | k 大将缩小调频范围但增加环流，折中取 k≈6 |
| 品质因数 | Q | 0.3–0.5 | Q 大会提高峰值增益但降低效率，按满载 Qmax=0.4 设计 |
| 谐振电容 | Cr | 44nF | 由 `Cr = 1/(2π·fr·Q·Rac)` 确定 |
| 谐振电感 | Lr | 50μH | 由 `Lr = 1/((2πfr)²·Cr)` 反推 |
| 励磁电感 | Lm | 300μH | 由 `Lm = (k-1)·Lr` 确定，k=6 |

### 2.3 ZVS 边界校核

原边 ZVS 的充要条件：死区时间内励磁电流峰值能够抽走桥臂中点结电容电荷。

```
Im_pk ≥ (2·Coss·Vin) / td

其中：
  Im_pk = Vin/(4·Lm·fr)  — 励磁电流峰值
  Coss ≈ 150pF             — SiC MOSFET 等效输出电容（800V 偏压）
  td ≈ 200ns               — 死区时间
```

校核结果：全输入电压范围、20%–100% 负载均满足 ZVS 条件，裕量 ≥30%。

## 3. 功率器件选型与损耗分析

### 3.1 SiC MOSFET 选型

| 考虑因素 | 分析 |
|---|---|
| 电压应力 | 800V 直流母线，考虑 30% 尖峰裕量 → 1200V 器件 |
| 电流应力 | 20kW/800V = 25A 平均输入，谐振峰值约 √2 倍 → ≥35A 峰值 |
| 导通电阻 | 直接影响导通损耗，SiC 1200V 器件 Rds(on) 典型 15–40mΩ（25°C） |
| 开关损耗 | SiC 关断极快 (tf<20ns)，关断损耗大幅低于 Si IGBT |
| 结电容 | Coss 小有利于 ZVS 实现，降低死区时间要求 |

### 3.2 全工况损耗计算

损耗分为以下部分：

**原边 MOSFET 损耗：**
- **导通损耗**：`Pcond = Irms²·Rds(on)`，Rds(on) 按 Tj=125°C 折算（约 1.8–2.0 倍常温值）
- **关断损耗**：`Poff = 0.5·Vin·Id_off·tf·fs`，Id_off 为关断时刻谐振电流瞬时值
- **开通损耗**：ZVS 实现后近似为零
- **体二极管损耗**：死区时间内续流，占比极小

**副边整流二极管损耗：**
- **导通损耗**：`Pcond = Vf·Iavg + Rd·Irms²`
- **反向恢复**：SiC SBD 为零反向恢复电荷，无此项

**磁性元件损耗：**
- 变压器铁损（Steinmetz 方程） + 铜损（含趋肤效应和邻近效应修正）
- 谐振电感铁损 + 铜损

### 3.3 效率估算

| 损耗项 | 满载估算 |
|---|---|
| 原边 SiC MOSFET（4颗） | ~120W |
| 副边整流 SiC SBD | ~80W |
| 变压器 | ~60W |
| 谐振电感 | ~30W |
| 辅助电源 + 其他 | ~30W |
| **总损耗** | **~320W** |
| **满载效率** | **98.4%** |

## 5. 控制策略

### 5.1 双闭环变频控制

```
Vref → [电压PI] → Iref → [电流PI] → fs → [PFM发生器] → 全桥驱动
         ↑                          ↑
       Vout采样                   Ires采样
```

- **电压外环**：采样输出电压，经 PI 调节输出电流环参考值
- **电流内环**：采样谐振电流峰值/平均值，调节开关频率 fs
- **PFM 输出**：固定 50% 占空比互补 + 死区，仅调频率

### 5.2 多模块无主从均流

采用**母线峰值电流法**实现无主从并联均流：

- 各模块在直流母线上注入与自身输出电流成比例的高频电流信号
- 各模块检测母线合成信号 → 提取均值 → 调节自身输出使偏差归零
- 无主从结构：无中央控制器，任一模块故障不影响其余模块
- 仿真验证：10 台并联均流偏差 < 2%

### 5.3 基于 STM32 的实现

| 外设 | 功能 |
|---|---|
| ADC | 输出电压、谐振电流、输入电压采样 |
| HRTIM | 高分辨率 PWM 生成（互补 + 死区 + PFM） |
| DAC + 比较器 | 峰值电流硬件保护 |
| UART | 模块间通信、上位机监控 |

## 7. PCB 设计

完成 20kW 主电路 PCB 设计（`pcb/` 目录下的 Gerber 文件）。

关键设计要点：

- **大电流走线**：原边 800V/25A 回路采用大面积铜皮 + 开窗加锡，温升 < 30°C
- **爬电距离**：800V DC 按加强绝缘 ≥ 8mm 设计
- **功率环最小化**：MOSFET → 变压器 → 整流桥 的物理环路最短化，降低寄生电感
- **驱动回路**：SiC MOSFET 驱动回路独立返回，避免 di/dt 耦合干扰
- **开尔文连接**：SiC MOSFET 源极开尔文引出，避免功率地干扰栅极驱动
- **热管理**：MOSFET 和整流桥底部大面积铜皮散热 + 过孔阵列导热

## 8. 电压采样板

LLC 变换器需要实时监测 ±200V 高压直流母线电压，为此设计了基于 STM32G474 的双路隔离电压采样板。

详见 [`../voltage-sampling/`](../voltage-sampling/) 目录。

### 8.1 硬件架构

```
±200V → AMC1350 隔离放大器 → TLV9002 信号调理 → STM32G474 ADC → OLED 显示
                                                              → HRTIM PWM 输出
```

| 环节 | 器件 | 说明 |
|---|---|---|
| 隔离采样 | AMC1350 | TI 差分隔离放大器，±5V 输入，隔离耐压 5kV |
| 信号调理 | TLV9002 | 差分转单端 + 电平移位到 0–3.3V |
| MCU | STM32G474RBT6 | 12-bit ADC，170MHz，HRTIM |
| 显示 | 0.96" OLED | I2C 接口，实时电压 + 诊断信息 |

### 8.2 关键参数

| 参数 | 值 | 说明 |
|---|---|---|
| 采样范围 | ±200V DC | 对应 LLC 直流母线正负轨 |
| ADC 分辨率 | 12-bit | 4096 LSB |
| ADC 时钟 | 10.6MHz | SYSCLK/16，异步时钟方案 |
| 采样时间 | 640 周期 (~60μs) | 平均 LLC 107kHz 开关纹波 |
| 基线 VCM | 1.645V | 0V 输入时的 ADC 读数基线 |
| 增益 K | 0.0066 V/V | 分压比 + 隔离放大器增益 |
| 参考电压 | VDDA = 3.3V | |
| 平滑滤波 | 指数平滑 τ≈0.3s | 抑制噪声同时保持响应 |

### 8.3 固件关键设计

**ADC 时钟排障：** CubeMX 默认生成的 PLL + 同步时钟配置导致 ADC 就绪标志 (ADRDY) 不置位，HAL 库 1ms 超时无法启动 ADC。根因是 G4 系列 ADC 时钟路径与 F1/F4 不同，需手动配置 `RCC_ADC12CLKSOURCE_SYSCLK` + `ADC_CLOCK_ASYNC_DIV16`。

**启动诊断：** `vs_adc_startup_diag()` 手动使能 ADC 并轮询 ADRDY（最长 50ms），记录就绪耗时和设备 ID，通过全局变量 `g_diag_adrdy`、`g_diag_elapsed`、`g_diag_devid` 暴露诊断信息。

**校准机制：** `VS_VCM_DEF`（0V 输入基线电压）和 `VS_K`（增益系数）在 `voltage_sample.h` 中定义为可调宏，支持硬件差异校准。

**OLED 显示布局：**
```
Vp: +150.2V     ← 正轨电压
Vn: -148.7V     ← 负轨电压
RAW: 2048 2051  ← ADC 原始读数
E:0             ← ADC 错误码 (0=正常)
```

### 8.4 固件文件说明

| 文件 | 功能 |
|---|---|
| `src/main.c` | 主循环：OLED 刷新、HRTIM 输出、100ms/64 样本平均 |
| `src/adc.c` | ADC1/ADC2 初始化，双通道顺序转换，错误码记录 |
| `src/voltage_sample.c` | 采样核心：原始值读取 `vs_read_counts()`、平均 `vs_read_rails_avg()`、电压换算 `vs_rail_voltage()` |
| `src/voltage_sample.h` | 采样参数宏定义 (`VS_VCM_DEF`, `VS_K`, `VS_ADC_VREF`, `VS_ADC_BITS`) |
